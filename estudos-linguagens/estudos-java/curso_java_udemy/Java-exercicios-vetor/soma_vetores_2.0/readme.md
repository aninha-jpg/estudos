# 📊 Exercício - Soma de Vetores

## 📌 Problema
Fazer um programa que leia dois vetores **A e B**, cada um com **N elementos**.

Em seguida, gerar um terceiro vetor **C**, onde:
- C[i] = A[i] + B[i]

Por fim, imprimir o vetor resultante.

---

## 🎯 Objetivo
- Trabalhar com vetores
- Usar estruturas de repetição
- Operações entre arrays
- Manipulação de dados em paralelo

---

## ⌨️ Entrada
- Um inteiro N
- N valores do vetor A
- N valores do vetor B

---

## 🖥️ Saída
- Vetor C com a soma dos elementos
