# 🛒 Gerenciador de Lista de Compras

Sistema desenvolvido para praticar os fundamentos da linguagem Java.

Permite que o usuário gerencie um carrinho de compras, controlando o saldo disponível e formatando a saída de dados.

## 🛠️ Conceitos Praticados

* **Sintaxe Moderna:** Uso de switch expression (`->`) para um código mais limpo.
* **Orientação a Objetos:** Criação da Classe `Item` com construtores e atributos.
* **Estruturas de Repetições:** `while` para o menu principal e `for-each` para percorrer a lista de compras.
