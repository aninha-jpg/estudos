# Exercício - Pensionato

## Problema
Fazer um programa que leia um conjunto de 0-9 e insira no quarto seleciona.

Os dados devem ser armazenados em um vetor de objetos.

Em seguida:
- Mostrar nome, email e quarto.

---

## Objetivo
- Trabalhar com classes e objetos
- Uso de vetores de objetos
- Estruturas de repetição

---

##  Entrada
- Um inteiro N
- Nome, email e quarto de N pessoas

---

## 🖥️ Saída
- Nome, email e quarto correspondente.
