# 📁 Lendo e escrevendo arquivos em Java

Utilizando: `FileReader`, `BufferedReader`, `FileWriter` e `BufferedWriter`
Para leitura e escrita de arquivos e tratando exceções como: `IOException`, `FileNotFoundException` para entrada e saída dos dados.

# 🛠️ Tecnologias
- Java
- FileReader
- BufferedReader
- FileWriter
- BufferedWriter

# 📚 Conceitos praticados
- Leitura e escrita de arquivos texto
- Manipulação de streams de entrada
- Tratamento de exceções
- IOException
- FileNotFoundException
- Boas práticas com try-catch


# 🎯 Objetivo

Compreender como realizar a leitura e escrita de arquivos de forma segura em Java, tratando possíveis erros, como arquivos inexistentes ou falhas.
