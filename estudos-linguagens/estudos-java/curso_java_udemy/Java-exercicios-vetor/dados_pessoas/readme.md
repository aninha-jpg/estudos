# 📊 Exercício - Dados das Pessoas

## 📌 Problema
Ler altura e gênero (M/F) de N pessoas.

Depois:
- Maior altura
- Menor altura
- Média de altura das mulheres
- Número de homens

---

## 🎯 Objetivo
- Vetores de objetos
- Estatísticas (média, máximo, mínimo)
- Estruturas de repetição
- Filtragem por condição

---

## ⌨️ Entrada
- Um inteiro N
- Altura e gênero de cada pessoa

---

## 🖥️ Saída
- Maior altura
- Menor altura
- Média das mulheres
- Número de homens
