# 🔢 Exercício - Média dos Pares

## 📌 Problema
Fazer um programa que leia um número inteiro **N** e depois um vetor com **N números inteiros**.

Em seguida:
- Calcular a média apenas dos números pares
- Se não houver números pares, mostrar a mensagem.

---

## 🎯 Objetivo
- Trabalhar com vetores
- Estruturas de repetição
- Operador módulo (%)
- Cálculo de média condicional

---

## ⌨️ Entrada
- Um inteiro N
- N números inteiros

---

## 🖥️ Saída
- Média dos números pares (1 casa decimal)
- Ou mensagem de ausência de pares
