# 📁 Lendo arquivos em Java

Utilizando: `FileReader`, `BufferedReader`
Para leitura de arquivos e tratando exceções como: `IOException`, `FileNotFoundException` para entrada e saída dos dados.

# 🛠️ Tecnologias
- Java
- FileReader
- BufferedReader

# 📚 Conceitos praticados
- Leitura de arquivos texto
- Manipulação de streams de entrada
- Tratamento de exceções
- IOException
- FileNotFoundException
- Boas práticas com try-catch


# 🎯 Objetivo

Compreender como realizar a leitura de arquivos de forma segura em Java, tratando possíveis erros, como arquivos inexistentes ou falhas durante a leitura.
