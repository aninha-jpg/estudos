# 🎓 Exercício - Alunos Aprovados

## 📌 Problema
Fazer um programa que leia o nome e as notas de dois semestres de N alunos.

Os dados devem ser armazenados em um vetor de objetos.

Depois:
- Calcular a média de cada aluno
- Mostrar apenas os alunos com média ≥ 6.0

---

## 🎯 Objetivo
- Trabalhar com classes e objetos
- Uso de vetores de objetos
- Cálculo de média
- Estruturas de repetição
- Filtragem de dados

---

## ⌨️ Entrada
- Um inteiro N
- Nome + 2 notas de cada aluno

---

## 🖥️ Saída
- Nome dos alunos aprovados
