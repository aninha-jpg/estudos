# 📘 Vetores em Java

Repositório com exercícios resolvidos do módulo de vetores do curso de Java, do professor Nelio Alves..

## 📊 Conteúdo estudado
- Vetores (arrays)
- Objetos em vetores
- Percorrer estruturas com for
- Filtros e condições

## 🚀 Objetivo
Praticar o uso de vetores em Java, desenvolvendo lógica de programação e consolidando o entendimento de estruturas básicas de dados.

## 💡 Observação
Este repositório contém apenas os exercícios da seção de vetores do curso.
