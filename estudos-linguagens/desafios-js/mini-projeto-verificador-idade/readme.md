# 🕵️‍♂️ Verificador de Idade

Um projeto interativo desenvolvido em HTML, CSS e JavaScript que calcula a idade do usuário com base no ano de nascimento, identifica o gênero e exibe uma imagem correspondente à faixa etária detectada.

## 🚀 Funcionalidades
* **Identificação de Perfil:** Diferencia entre Masculino e Feminino.
* **Interface Dinâmica:** Altera o conteúdo da página e exibe imagens específicas para:
    * Criança (0-10 anos)
    * Jovem (11-20 anos)
    * Adulto (21-49 anos)
    * Idoso (50+ anos)
* **Validação de Dados:** Impede a inserção de anos futuros ou campos vazios.

## 🛠 Tecnologias Utilizadas

* HTML5: Estruturação semântica.

* CSS3: Estilização.

* JavaScript: Lógica de cálculo, manipulação de elementos DOM e criação dinâmica de imagens.

## 💻 Como executar o projeto

1.  Clone este repositório:
    ```bash
    git clone https://github.com/aninha-jpg/estudos.git
    ```
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` no seu navegador de preferência.
