# 📊 Exercício - Negativos

## 📌 Problema
Fazer um programa que leia um número inteiro positivo **N**. Em seguida, ler **N números inteiros**, armazenando-os em um vetor.

Depois, o programa deve mostrar na tela apenas os **números negativos** digitados.

## 🎯 Objetivo
Praticar:
- Uso de vetores (arrays)
- Estrutura de repetição
- Condicional (if)
- Filtragem de valores em um array

## ⌨️ Entrada
Um inteiro N (1 a 10) seguido de N números inteiros.

## 🖥️ Saída
Todos os números negativos informados pelo usuário.
