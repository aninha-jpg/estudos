# 👴 Exercício - Pessoa Mais Velha

## 📌 Problema
Fazer um programa que leia um conjunto de nomes e idades de pessoas.

Os dados devem ser armazenados em um vetor de objetos.

Em seguida:
- Encontrar a pessoa mais velha
- Mostrar seu nome e idade

---

## 🎯 Objetivo
- Trabalhar com classes e objetos
- Uso de vetores de objetos
- Estruturas de repetição
- Busca do maior valor

---

## ⌨️ Entrada
- Um inteiro N
- Nome e idade de N pessoas

---

## 🖥️ Saída
- Nome da pessoa mais velha
- Idade correspondente
