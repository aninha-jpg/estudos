# Exercício - Números Pares

## Problema
Fazer um programa que leia um número inteiro **N** e depois leia **N números inteiros**, armazenando-os em um vetor.

Em seguida, o programa deve:
- Mostrar todos os números pares digitados
- Mostrar a quantidade de números pares

## Objetivo
Praticar:
- Uso de vetores (arrays)
- Estrutura de repetição
- Condicional (if)
- Operador módulo (%)
- Contagem de elementos

## Entrada
Um inteiro N seguido de N números inteiros.

## Saída
- Todos os números pares
- Quantidade de números pares
