# Herança e Polimorfismo em Java

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)
![POO](https://img.shields.io/badge/POO-Programação%20Orientada%20a%20Objetos-purple?style=for-the-badge)

Projeto com exercícios práticos sobre os principais conceitos de Programação Orientada a Objetos (POO) em Java.

## 📚 Conteúdos abordados

- Herança
- Upcasting e Downcasting
- Sobreposição de métodos (`@Override`)
- Uso da palavra `super`
- Classes e métodos `abstract`
- Polimorfismo
- Classes abstratas
- Métodos abstratos

## 🛠️ Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)

## 🎯 Objetivo

Praticar os conceitos fundamentais de herança e polimorfismo em Java através de exercícios e exemplos práticos.
