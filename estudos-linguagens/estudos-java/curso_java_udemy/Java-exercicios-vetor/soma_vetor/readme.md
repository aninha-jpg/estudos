# 📊 Exercício - Soma de Vetor

## 📌 Problema
Fazer um programa que leia um número inteiro **N** e depois leia **N números reais**, armazenando-os em um vetor.

Em seguida, o programa deve:
- Imprimir todos os elementos do vetor
- Calcular e mostrar a soma dos elementos
- Calcular e mostrar a média dos elementos

## 🎯 Objetivo
Praticar:
- Uso de vetores (arrays)
- Estrutura de repetição
- Soma de elementos
- Cálculo de média

## ⌨️ Entrada
Um inteiro N seguido de N números reais.

## 🖥️ Saída
Todos os elementos do vetor, a soma e a média dos valores.
