# Exercício - Alturas

## Problema
Fazer um programa para ler o nome, idade e altura de N pessoas.

Depois, o programa deve:
- Calcular a **altura média** das pessoas
- Calcular a **porcentagem de pessoas com menos de 16 anos**
- Mostrar os **nomes dessas pessoas**, caso existam

## Objetivo
Praticar:
- Vetores de objetos
- Criação de classe (Person)
- Encapsulamento
- Estrutura de repetição
- Cálculo de média e porcentagem
- Filtragem de dados

## Entrada
Um inteiro N seguido dos dados de N pessoas:
- Nome (String)
- Idade (int)
- Altura (double)

## Saída
- Altura média
- Percentual de menores de 16 anos
- Nomes das pessoas com menos de 16 anos (se houver)
