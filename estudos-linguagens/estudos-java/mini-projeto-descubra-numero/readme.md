# 🎯 Adivinhe o Número

Sistema desenvolvido para praticar os fundamentos da linguagem Java.

Jogo de console para adivinhar um número, gerado aleatoriamente pelo sistema, antes que seus palpites acabem.

## 🛠️ Conceitos Praticados

* **Sintaxe Moderna:** Uso de switch expression (`->`) para um código mais limpo e do `try-with-resources` para garantir o fechamento do `Scanner`.
* **`java.util.Random`:** Geração de números aleatórios;
* **`do-while`:** Para garantir que o jogador faça pelo menos 1 jogada.
