# 📉 Exercício - Abaixo da Média

## 📌 Problema
Fazer um programa que leia um número inteiro **N** e depois um vetor com **N números reais**.

Em seguida:
- Calcular a média dos elementos (com 3 casas decimais)
- Mostrar os elementos que estão **abaixo da média**

---

## 🎯 Objetivo
- Trabalhar com vetores
- Cálculo de média
- Estruturas de repetição
- Filtragem de dados

---

## ⌨️ Entrada
- Um inteiro N
- N números reais

---

## 🖥️ Saída
- Média do vetor
- Elementos abaixo da média
