# Exercício - Maior Posição

## Problema
Fazer um programa que leia um número inteiro **N** e depois leia **N números reais**, armazenando-os em um vetor.

Em seguida, o programa deve:
- Mostrar o **maior número do vetor**
- Mostrar a **posição (índice) do maior elemento**
  (considerando o primeiro índice como 0)

## Objetivo
Praticar:
- Uso de vetores (arrays)
- Estrutura de repetição
- Busca do maior valor
- Controle de índice

## Entrada
Um inteiro N seguido de N números reais.

## Saída
- Maior valor do vetor
- Índice do maior valor
